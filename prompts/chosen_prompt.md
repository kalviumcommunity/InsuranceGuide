# Chosen System Prompt

The structured system prompt was selected because it clearly defines the assistant's role, scope, and response constraints.

Why it works better:
- Defines the assistant as an insurance support assistant.
- Restricts answers to insurance-related topics.
- Prevents unsupported or invented information.
- Produces concise, professional, and well-formatted responses.
- Includes a fallback response when sufficient information is unavailable.

Compared to the vague prompt, the structured prompt generated more consistent and reliable answers that are better suited for a Retrieval-Augmented Generation (RAG) assistant.
